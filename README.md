## Menagerie

[`Menagerie/`](Menagerie/) is a native macOS app, designed and written by Claude. It is a gallery of nine interactive exhibits: GPU fractals, a path tracer, artificial life, maze search, computer algebra, a Connect Four engine, on-device linguistics, sonified sorting and a synthesizer. See [its README](Menagerie/README.md) to build and run it.
